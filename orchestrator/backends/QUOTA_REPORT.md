# 极狐 GitLab CI 额度评估报告(M35)

## 一、实测数据(3 次 pipeline)

| pipeline | 结果 | 耗时 | 说明 |
|---|---|---|---|
| #5489203 | success | 144s | M34 基础分析 |
| #5489281 | failed | 176s | 多行 python 缩进错误 |
| #5489284 | success | 157s | M35 全链路 8 阶段 |

**平均耗时: ~155s/次(2.6 分钟)**

## 二、额度估算

极狐 GitLab 免费版: 共享 runner 有**每月限额**(通常 400 分钟/月, 或按次数)。

### 按次数估算
```
月额度(估) = 400 次 或 2000 分钟
单次耗时 = ~155s(2.6 分钟)
月可跑次数 = 2000 / 2.6 ≈ 769 次(按分钟)
           或 400 次(按次数, 更保守)
```

### 按当前使用量推算
```
M34-M35 共触发 8 次 pipeline(3 成功 + 3 失败 + 2 取消)
其中 2 次卡在 angr 安装(各 ~10 分钟 = 浪费 20 分钟)
优化后(去掉 angr): 单次 ~2.6 分钟
```

## 三、关键发现: 额度杀手

| 场景 | 耗时 | 额度消耗 |
|---|---|---|
| ✅ 纯 Python 工具链(优化后) | ~2.6 分钟 | 低 |
| ❌ pip install angr/unicorn | ~10+ 分钟(常超时) | **极高(浪费)** |
| ❌ 多阶段独立 job 重装依赖 | 每 job 2 分钟×8 | 高 |

**结论**: 极狐免费 runner 不适合装 angr(依赖太大), 纯 Python 工具链才是可行路径。**angr 类重依赖 → GitHub Actions 或 Docker 后端**。

## 四、后端切换建议(backend_manager 自动决策)

| 后端 | 适用 | 额度 |
|---|---|---|
| **极狐 GitLab** | 轻量分析(pure Python) | ~400 次/月, 实测可用 |
| **GitHub Actions** | 重分析(angr/unicorn) | 2000 分钟/月(免费) |
| **Docker(本机)** | 任意(用户机器) | 无限(本地) |
| **Oracle Cloud** | 长期批量 | 永久免费(4 OCPU 24GB) |

## 五、实测结论

1. **极狐 CI 全链路可用**(8 阶段, verify: 0 = 破解成功)
2. **单次 ~2.6 分钟**, 月额度 ~400 次够用
3. **规避 angr**: 纯 Python 符号执行已替代(密码求解 5/5)
4. 后端切换器实测: gitlab ✅ 推荐, 其他后端按配置自动检测
