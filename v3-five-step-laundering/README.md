## 三、脱敏词表(转录 618s-635s)

> "我也给大家做了一些脱敏词的这样的一个替换点, 比如说绕窝登录,
> 我们这个是分析认证。你跟 AI 去说的话, AI 不会去给你进行一个拒绝。"

| 原词(高风险) | 替换(中性工程表述) |
|---|---|
| 绕过登录 | 分析认证流程 |
| 绕过卡密 / 去除卡密 | 分析卡密校验逻辑 |
| 破解软件 | 分析软件结构 |
| 破解 | 分析 |
| 打补丁 | 验证程序行为 |
| 去卡密 | 分析授权校验 |
| ... 共 18 条 | 见 `data/laundering_map.yaml` |

**机制**:
- `replace(text)`: 逐条替换, 返回 {text, replaced, count}
- `judge_intent(text)`: 判定意图(第三方高风险 vs 自有中性)+ 结果导向动词
